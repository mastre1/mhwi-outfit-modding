
# 诊断症状与对照设计

先写下哪一个观察能够推翻当前判断。在相同编号、动作、视角、距离和光照下看原版或已知正常的装扮，再做一次只改一个变量的导出。记录哪些结论来自实机，哪些来自结构、渲染或推断。旧案例证据用于选择第一轮对照，不能替新角色下结论。

## 体态、手指和贴身衣物

- 从模型全局判断骨长时用相邻关节的 bone head 位置，优先试头到颈根、肩到肘、肘到腕、髋到膝和膝到踝。在某些 MOD3 导入器中 Blender bone tail 只是用于显示的 5 cm 占位。体型整体有偏差时先对齐成套关节，配件和接缝一起跟动。需要判断两个素材身体是否同源时，用多个对应骨头拟合轴置换、统一尺度和平移，再看逐骨残差与网格形状。文件名、角色名和两三个点相似会误判。
- 手指在特定手势折错时，先选可见手部的原版或已知正常模型做同动作。沿实际手指关节标记静置网格的顶点集合，核对食中无名指受邻指和手掌的权重。在目标姿态上比较同一批边长的 `posed/rest` 或其对数的高分位和局部轮廓。静置对静置应为 1，测试还应能区分已知坏与好样本。按权重总量猜哪个手指能弯容易得到通过但实机没改善的结果。
- 袜、鞋、护臂等和身体分属不同 MOD3 时，先比较踝腕过渡带的静置高度、主骨权重和动画。皮肤与衣物用了不同过渡带时会随动画错开，直接加厚通常只推迟穿模。把对应一侧皮肤权重作为供体，按最近面插值或近邻距离混合，把修改限制在需要的过渡段。保留未选择顶点原权重。尤其要照原作者已适配的轮廓做小步修订，避免先重塑整套袜子。
- 测贴身余量时，静置时给衣物与皮肤标记稳定的最近点对，在多姿态中跟踪同一对的距离变化，再定各点需要的静置间隙。每个姿态重新找最近点容易从小腿跳到脚掌，读出虚假的相对位移。检查穿出皮肤的顶点时，应在静置时按区域选点，再用姿态空间外法线的射线或三角重叠检查；裙子等遮挡纳入判断。
- 每次核对导出侧实际数量、有限权重、三角面、索引范围及一致的关节缝。导出器会在 UV／法线缝拆点，重导的浮点末位、时间戳和权重量化也会变化。对比导出和 Blender 顶点时用位置与分件、面角对应。只有采用定长补丁并核对字节差异时才声称其余字段逐字节一致。

在兼容版本的 Blender 中，可先生成三角化供体，以 `BVHTree.FromPolygons` 构建同侧/同部位世界坐标 BVH，再对目标顶点调用 `find_nearest`，按命中三角形的重心组合三点权重。或使用 Data Transfer 修改器，设置源 `object`、`use_vert_data=True`、`data_types_verts={'VGROUP_WEIGHTS'}`、`vert_mapping='POLYINTERP_NEAREST'`，使用版本支持的遮罩和范围。在 UI 核对生成的组，再应用修改器。修改骨约束在 Pose Bone，骨头基线在编辑骨。在 Blender 4.3 使用求值网格时应让 `to_mesh()` 和 `to_mesh_clear()` 操作同一个求值对象。[Blender DataTransferModifier API](https://docs.blender.org/api/4.3/bpy.types.DataTransferModifier.html)

## 脸上斑驳、雪地发白或发光过强

1. 首先拆最终交付包里的 TEX，在固定 UV 和机位下与源图对照。在同灯下把基色换成纯色。如果斑驳持续，逐个关闭投影、隔离主连通分量、检查重叠几何和法线。如果纯色干净，按顺序看活动贴图槽、原始 alpha、颜色空间、mip 边缘，最后才调常量掩盖现象。
2. 对几何用 `mesh.corner_normals` 与同面角对应 `vertex_normals` 算夹角分布，在应平滑的脸颊／鼻梁上定位异常朝向，并与已知正常部位对照。光滑区大面积反向时在副本尝试清除 custom split normals，复验位置、面索引和绕序不变。硬边、发片和刻意造型单独评估。
3. 若 MRL3 确认这一区域应完全不透明，源 alpha=0 处却只有白或黑底，mip 会把底色拖进小岛。用正确 UV 覆盖和岛内有效边缘颜色扩展空白，再对该用途考虑置不透明。检测岛覆盖时镜像 UV 的三角绕序也要支持。验证有意义颜色像素保持不变。半透明纱、头发卡片、眼缘或源明确以 alpha 储存数据时保留语义，分别看 premult 和 shader。
4. 法线颜色空间错误比简单翻绿更基础。用线性样本看平坦区双通道是否接近中值，做固定光线的起伏 A/B，并检查源与解码后的数值是否有意外 gamma。绿通道全图平均值对左右/上下混杂的内容证明力很低。先核对已知平坦区和特定凸凹特征，再决定翻转。
5. 发光、底色强弱、镜面和雪地混合联动时，优先对照兼容 MMTR 的实际活动槽及纹理内容。只借用参考系数而不看参考贴图亮度或遮罩语义，容易得到完全不同的亮度。Alpha、色彩空间、发光因子和混合图逐项对照。源包如提供 prefab、slotmap 或材质清单，以它们确定原配槽，再用预览工程补充。

## 可选的反壳描边

任务确实需要时，复制适合描边的闭合或主要外轮廓，沿正常外法线少量偏移，反转三角绕序，并赋予独立描边材质。从兼容且已验证的 MRL3 描边材质核对剔除、alpha、雪地混合与资源绑定。给贴片、蝴蝶结和发绳预留排除带，防止被邻近的壳盖成一块黑色。清掉因排除带留下的孤立顶点。用壳顶到原表面距离的中位和高分位检查外扩是否符合目标。开口衣片的有符号体积可能给出错误方向。描边完成后再全套读回，避免后一步材质覆盖把描边项抹掉。

## 工程与复核

- 每阶段另存新工作文件。Blender 后台使用 `--python-exit-code 13`，插件打印成功后仍要验证文件存在、非空、可读回。个别插件版本的控制台开关会导致后台导入失败，先切纯后台并用已知可导入的原版文件区分环境故障与资产故障。
- 权重传递放在局部修订之前。一轮给同一子网格多次全量重建组会覆盖前一轮结果。看到 Blender 崩溃时，从最近可打开的副本重现一次，在单个进程单步运行或用 UI 做最小赋值。读输出比猜测崩溃原因有效。
- 数值对照先断言样本非空、点选确实落在有症状的部位，有正常和异常样本作标定。脚本日志至少打印实际改变的点数及比例、异常点的部位，排除空集合、错索引或仍在使用旧包的假通过。
- 最终只修几何时保留已验收包作底，用 ZIP 条目名和 SHA256 验证只替换计划中的文件。并行改材质与模型时明确谁写哪些文件，再从共同的稳定基线合并。
